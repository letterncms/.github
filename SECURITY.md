# Security policy

Please don't report a vulnerability in a public issue. Report it privately through [GitHub's security advisories](https://github.com/letterncms/cms/security/advisories/new).

Say what you found, how to reproduce it and which version it affects. Security updates are free for every site and need no account or key.

[Security in the docs](https://github.com/letterncms/docs/blob/main/content/collections/docs/operations/security.md) explains how a site is protected.
